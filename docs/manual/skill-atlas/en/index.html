Skill Atlas AI Reference

Local Skills

Start a session

Open Skill Atlas in ego lite. Check both folder connections and report the names and skill counts before waiting for the next task.

Connect folders

In Local Skills inspect Local Folder and Team Folder separately. A black folder icon means connected. Clicking it disconnects it. For missing connections ask the user to choose the current Workbench skills folder or the synced Shared-Skills folder. An empty connected folder can show zero skills. Refresh after changes and compare paths in Catalog.

Install a team skill

Read Team guide in Catalog. Choose Local setup prompt → Copy prompt. Paste into a new Workbench chat with your data folder, language and purpose. Compare existing installations first. Keep the team original and provide a permitted copy if the workspace cannot access it.

Run and follow up

Use /mmemo in a new chat with a synthetic meeting and a destination memo. Repeat one decision and add an owner. Reopen the memo and verify the decision appears once, the open question remains open and the new owner appears once.

Share a skill

Review the audience and use in Local Skills. Preserve the command name. Replace personal accounts and paths with setup instructions and synthetic examples. Follow team review and refresh Team Folder.

Evaluate a run

Open Evaluate this skill. Paste the evaluation prompt into the original Workbench chat, return the observed JSON to Atlas and complete the human judgement fields.

Recover a missing skill

Check the selected folder, SKILL.md and team sync. Use synthetic data on the first run. Ask the user to handle login, file selection or permissions.
