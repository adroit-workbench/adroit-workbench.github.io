Skill Atlas AI Reference

Workbench 요청에 이 URL을 넣으세요. Sources가 파일만 받으면 URL을 담은 노트를 연결하세요. AI는 사용자 요청에 해당하는 절차를 골라 실행하고, 로그인과 폴더 선택은 사용자에게 요청합니다.

처음 연결하도록 요청받았을 때

ego lite에서 Skill Atlas를 열고 개인 폴더와 팀 폴더 선택을 안내하세요. 연결 후 각 폴더의 이름과 발견한 스킬을 보여주고 다음 요청을 기다리세요.

폴더를 처음 연결할 때

  1. ego lite에서 Local Skills를 열고 본인 계정으로 로그인하세요.
  2. Local Folder에서 폴더 아이콘을 눌러 현재 Workbench의 skills 폴더를 선택하세요. 비어 있으면 0개가 정상입니다.
  3. Team Folder에서 팀이 제공한 Shared-Skills를 선택하세요. 검은 아이콘은 연결된 상태입니다. 다시 누르면 연결이 해제됩니다. 변경된 파일은 새로고침으로 다시 읽으세요.
  4. Catalog에서 스킬 이름과 Team folder 경로를 대조하세요. 브라우저의 목록 연결과 Workbench의 로컬 설치는 별도입니다.

팀 스킬을 내 환경에 적용할 때

Catalog에서 스킬의 Team guide를 읽고 Local setup prompt → Copy prompt를 누르세요. Workbench 새 대화에 붙여넣고 내 자료 폴더, 언어와 사용 목적을 알려주세요. 팀 원본은 보존하고, 같은 이름의 개인 스킬이 있으면 차이를 먼저 확인하세요. Workbench에서 팀 폴더를 읽을 수 없다면 허용된 사본을 Source로 제공하세요.

새 세션에서 실행하고 이어 쓸 때

설치한 이름을 새 대화에서 호출하세요. 예를 들어 /mmemo에 “내부 데모는 월요일로 결정했다. 금요일 리허설은 가능한지 질문이 나왔다”를 주고 정리할 메모 경로를 지정하세요. 후속으로 “월요일 결정은 그대로이고 리허설 담당은 Mina다”를 주고 같은 문서에 추가하세요. 합격 기준은 월요일 결정 한 건, 금요일은 미확정, 새 담당 한 건입니다. 문서를 다시 열어 확인하세요.

내 절차를 팀에 공유할 때

Local Skills에서 개인 폴더의 스킬을 열고 사용 대상과 실제 쓰임을 확인하세요. 팀용 사본에는 개인 경로·계정 대신 각자 준비할 자료와 합성 예시를 넣으세요. 원래 호출명을 유지하고 팀의 검토 절차에 따라 Shared-Skills에 저장한 뒤 Team Folder를 갱신하세요.

사용 결과를 남길 때

배포된 스킬 카드에서 Evaluate this skill을 열고 평가 프롬프트를 실제 실행한 Workbench 대화에 붙여넣으세요. 관측된 결과만 담은 JSON을 Atlas에 붙여넣고 사람의 판단 항목을 선택하세요.

목록이나 호출이 보이지 않을 때

폴더가 맞는지, 해당 폴더 아래에 SKILL.md가 있는지, 팀 동기화가 끝났는지 순서대로 확인하세요. 첫 실행에서는 팀 계정의 자료 대신 합성 예시를 사용하세요. 로그인, 파일 선택, 권한 승인 또는 사용권 활성화가 필요한 경우에는 사용자에게 해당 조작을 요청하세요.
