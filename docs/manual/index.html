Getting Started: Installation·License·AI Connection

Verify your Workbench license and connect the AI account you will actually use.

Reviewed for Workbench 0.20.13

Where can I use it?

Check the connection/license status in the Workbench section of Obsidian settings and the information icon at the top of the Workbench. You can open the task pane from the Obsidian command palette with Workbench: Open workbench.

Order of use

  1. Install Workbench and a supported desktop, Obsidian, and open the Documents folder you want to use. The minimum Obsidian version for 0.19.53 is 1.15.0.
  2. Authenticate with the issued key on the license screen and check the validity status.
  3. In the connection settings, check which Codex·Antigravity·Claude connection you want to use. Any required logins are completed directly from the app.
  4. After checking the connection, select the model that can actually be used from the model menu. Select Model·Effort·Usage
  5. This is your first time using Workbench. Check your attachments and answers with a short exercise.

Verification and troubleshooting

The Workbench license does not replace the right to use or use AI models. Even if you are logged in from another app, Workbench does not inherit all tools or accounts from that app. A distinction is also made between connection check success and individual mail/web service access success. After reissuing or renewing the key, check the new status on the license screen and reopen the existing session.

Examples of using together

In the settings, model connection and authentication is used to log in to the AI provider, and app and work account are used to connect work tools. Check license and update status at Installation·Update·License.

The titles of the Installation and Connections windows are Companion Apps, Workbench License, and AI Connections.

The information window User manual and Website and downloads open at adroit-workbench.github.io.

Feature guide · F02

Sources: Select and exclude references

AI visually checks which files will be used for this request.

Reviewed for Workbench 0.20.14

Where can I use it?

Use Sources, +, Open Tabs on the input window and Add to source on the right-click menu of the file.

Order of use

  1. Right-click the file and select Add to source, or add a file/folder path supported by +.
  2. To write multiple open documents, turn on Open Tabs. Duplicate tabs in the same file will not be attached.
  3. Check the Source name and number and expand +N Number to see the full list. Exclude unnecessary items as ×.
  4. Before sending, make sure the file is saved and contains the required parts.

Actions to be aware of

Folders are displayed as search scopes. When transmitting, select a file whose words from the request and selected skill match the subfile name/path or indexed title/tag. The default candidate is Markdown. If there are no search results, enter specific search terms or add files directly. You can append to the current session if it is idle even if another session is running. For other formats, please specify the file directly to check whether it is included. External files are readable and are not automatically copied to Vault or given permission to modify them. If you paste an unsupported path such as ZIP into the input window, it will remain as text. Just because the path is visible doesn't mean the file is attached.

Sources changes will take effect on the next request. Removing it from the current list does not erase the context you provided in the previous conversation. Start a new conversation if you don't want to use the previous context. If you encounter a limit error, narrow it down to the materials you need or review the on-screen limit adjustments for this request.

Examples of using together

Collect multiple materials and respond to customer emails Compare two proposals on the same basis Create weekly reports with records of multiple tasks Combining scattered project notes into one document

If you paste an external path that does not exist on this PC into the input box, the original text along with instructions will be entered as text. Preserves the entire input even if one of the multiple paths is missing. To attach a local file directly, use + to add path.

If you delete all unconfirmable routes from the input box, the guidance will also disappear. Hover over Sources to see if you have exceeded the default adjustable attachment limits.

Open Tabs in Sources turns automatic attachment of open files on or off. Clear clears the selected Sources. You can check your attachment limits with Attachment Limits and clean up duplicate file tabs with Close Duplicate Tabs.

When Sources is narrowed, an icon is displayed instead of a button title. When you hover the pointer, you can see the name of each button and the automatic attachment status of Open Tabs.

When running a skill without arguments, if the skill definition specifies that all files in a folder should be processed, support files from the selected folder will be attached. Skills that specify exclusions or scope restrictions use traditional topic selection methods.

Feature guide · F03

PDF · Image · External file reference

Ask questions while checking the document format and actual read scope.

Reviewed for Workbench 0.20.17

Order of use

  1. Select a supported PDF or image file by adding Add to source or + to the path. Sources: Select and exclude references
  2. For PDFs, please include the pages, tables, and items you would like to inquire about along with your request. Smaller text in an image prepares the area for reading more clearly.
  3. Please include the document name, page, or source location in your answer.
  4. Check the original text for important numbers and tables.

Scope and precautions

The PDF is delivered with text extraction and some page images. Not all diagrams on the entire page are conveyed as images. Encrypted PDFs require openable copies, and large scanned documents may need to be split. There are quantity and size restrictions on scanned page images.

External paths and cloud sync files must be physically readable by this PC. Do not consider the analysis complete without resolving any ‘not found’ or access errors that appear. Files that can be opened with a dedicated viewer and files supported by AI Source may be different.

Examples of using together

Compare two proposals using the same criteria Answer questions based on the document

PPTX reads slide text in the order it is presented. Pictures, charts, and presenter notes are excluded. EML reads the subject, sender, recipient, and body, and displays only the name of the attachment. For folders, please specify PPTX or EML in your request.

If there are multiple PDFs, the text extracted from the pages is totaled and the attachment limit for this request is checked at once.

EML and PPTX verify the original attachment and extracted text respectively. If you are notified that there are no extracted body verification values from the previous session, reattach the original in the new session.

When you select a local MP4, the Workbench previews the verified copy and reads the frames at the requested time.

Codex receives a visual preview of the video along with the transcription correction request and retrieves additional frames when needed. The propagation length of the result is the range you give to the model. This does not mean audio and full video review. If a preview cannot be provided due to attachment limits or decoding issues, the reason and viewing status will be displayed.

Temporary chat with selected files

In File Explorer, select one or more support files, right-click and select Temporary Chat. Only the selected files will be attached. When closed, temporary conversations will not remain in the saved sessions list. To save it, click Save as full session after answering. Even before the conversation, you can save the files you have selected and the request you are making. If you see a save error, keep the window open and try again.

If you select Side Chat in File Explorer, the selected file and the current session's conversation will be referenced together.

The title of the video connection window is Video Sources · Gemini API.

When requesting a list of skills from an external folder, select the accessible SKILL.md. If you specify a full file list, all allowed files will be targeted.

If you select Vault Folder as the Source and ask “Please open all MD files modified in this folder in the last 3 weeks in a tab,” it will open documents with modification times that meet the conditions, including subfolders. Already opened tabs are reused.

You can open recently modified Markdown files as tabs by specifying a range and period in Open Recent Markdown Tabs in the folder menu.

If you would like to reuse the video in your next request, please attach it to Sources. Videos that were only present in previous requests will not be automatically sent again.

Alt+Shift+click opens a file from the explorer in a new tab. With the standard multi-selection active, the Workbench link button opens documents linked to the selected files.

Feature guide · F04

Request creation/supplementation/immediate execution

Write down the purpose, scope of data, and type of results and execute them the way you want.

Reviewed for Workbench 0.20.14

Order of use

  1. Write down what you will do + what data you will use + what results you want. Example: ‘Please organize the decisions and tasks for each person in charge in a table in the attached memo.’
  2. Check the required source and model.
  3. To supplement your request, use the normal Enter flow in the input field and review the suggested follow-up questions/enhancement requests.
  4. To immediately execute the request you made, use Ctrl+Enter, or on macOS, use Ctrl+Enter. This skips the request supplementation step, but does not skip licensing, usage, or data checks.
  5. For multiple lines, enter Shift+Enter.

Prepare your next request while waiting for a response

Even while replying, you can write your next request in the input box. If you press Enter, Ctrl+Enter / Cmd+Enter or the Add Wait icon, it will be saved to the wait list in the same Session and will be executed in order after the current answer is finished. The Stop button stops the current execution.

To redirect the current task, use the Direct In Progress feature. Codex passes instructions to ongoing operations and uses an on-screen guided stop-and-continue flow for unsupported connections.

Wait requests are not automatically executed in the event of an error, if the user stops, or if the app is reopened. Check the list and resume. Since waiting requests use the Source and Model of the current Session, they are checked again before execution.

Verification and troubleshooting

Check the status and task history to see if you are generating an answer, waiting for an answer to your question, or stuck with an error. If there is only progress text and no final result, it is not considered complete. Enter in Korean combination can be used to confirm input. Make sure the input focus is on the request window and use the Submit button if necessary.

Quick Filter and Primary Filtering

The model selected in the First-pass Filter Model processes Prompt Complementation, Ask Before Answer, and Routing together. Automatic selects available models based on connection status, input format and remaining capacity. The execution model can be selected separately.

Quick Filter is displayed only when the selected first-order filtering model supports the Fast feature. When turned on, it will request faster processing for primary filtering and will not apply it to actual answers. Fixed speeds are not guaranteed and usage may increase, so check the rate information on the screen.

Long answers and on-screen responses

While you are writing your answer, open sessions will display up to the most recent 8,192 characters. You'll still receive answers even if you switch to another session, and you'll see the latest content when you return. Once completed, we'll display the entire answer up to 128,000 characters, and beyond that we'll display it in plain text starting from the last page. You can read the entire answer front to back with Earlier and Later. Use the full answer to copy and save.

If the entire Obsidian screen is white, don't judge whether the launch is complete based on the screen alone. Reloading may interrupt ongoing operations. First, record the error occurrence time and number of concurrent executions, and check the last completion status of the saved session after recovery. This screen load improvement does not guarantee automatic recovery from GPU/renderer exits.

Check Antigravity Tool Completion

If the tool is incomplete even though Antigravity has signaled the end of the response, it will check for a late completion event for up to 2 seconds. When the completion event arrives, it finishes in the same execution and does not re-execute the command.

If ANTIGRAVITY_INCOMPLETE_TOOLS continues to appear, check the tool ID/last status and unconfirmed range. This error alone does not determine whether the browser command failed or is still running. After checking the browser connection and actual execution results, continue making the same request. Do not repeat commands with side effects, such as sending messages, without checking the results.

Among the replies, please enter your next request and you can add it to the queue with the button on the right. Select Edit·Delete·Steer from the standby items.

Hover your mouse over the Vault document link in the answer to see the file path. Clicking on it will open it in a new tab. On Windows, file links that point to files in the current Vault open in the same way.

Likes on your answer will be saved even if you leave out additional comments. In Feedback, if you select 's answer modification request or 's skill modification request, a draft will be prepared in the input field. For instructions to use in the future, expand Save rules to apply in the future and specify the scope.

If you only need a specific draft or paragraph of your answer, drag the text and press Copy Selected. Please use the copy icon below for the full answer.

In responses with text for sending, copy the entire text excluding the explanation and evidence using copydraft. Multiple drafts each display a copy button.

If the field is empty and you see the next request suggestion, place focus in the field and press Tab to add your suggestion.

You can select a sentence from the answer to open Temporary Chat or Side Chat. Side Chat references conversations in the current session. If a code block already has a copy button, it won't show a duplicate copy button for that draft.

When inserting a wikilink with an alias into an Obsidian Markdown table, add a backslash before the alias. Workbench asks the model to confirm this format and number of columns.

The titles of the Ask Before Answer and Request Integrity Results windows are Ask Before Answer, Request Integrity Results.

Select the model to refine the request from First-pass Filter Model in Workbench settings. If the model you picked is not currently available for input, check your connections and usage or return to Automatic.

First-pass Filter Model's Automatic takes precedence over the latest Sol, Neon, or Sonnet available from the active provider. If the model you specified is not available, check connectivity, remaining capacity, or input compatibility.

Long prompts can be read by expanding them with Expand and then scrolling. Save your answers with Save to Note and copy the content for follow-up with Copy Handoff. While you're creating a long answer, you'll see a preview centered on your most recent answers. The original text of completed responses will be preserved.

Request complementation, confirmation questions, and execution model routing use the first-order filter model you set up. Expanded requests are displayed at an easy-to-read height.

If Antigravity delays the tool completion signal, the workbench waits up to 8 seconds. If there is confirmed output or a capture of this run, it will be used to continue the response and will not re-run the existing command. If you don't have enough verification data, you'll be prompted to check your run history.

Select Model · Effort · Usage

Choose the model and level of inference to use for the current task.

Reviewed for Workbench 0.20.17

Where can I use it?

When you click the model name below the input window, a menu expands upward. You can continue your selection from the currently selected model position.

Order of use

  1. Search in the Model menu or browse the list.
  2. If you click on the model name itself, the Effort of that model will be selected as Auto.
  3. Select a supported Effort from the adjacent submenu only when you need a specific level.
  4. Auto at the top of the menu is an item that leaves model selection to you. Distinguish from Effort Auto for a specific model.
  5. Expand the usage display to see connections, accounts, remaining limits, and when to reset.

Actions to be aware of

Even if you change the model, the same Workbench Session continues. Those conversations and Sources may be passed on to your next connection, so check the scope of data sharing before switching to another provider. Available features vary depending on the model as well as the launcher/connection tool. The indication of unconfirmed usage or renewal required is not read as the actual remaining figure.

Separately from the answer model, you can specify First-pass Filter Model. The default is Automatic.

There is no need to set up a separate Dify service for model routing. In the Workbench, select the connection model in the primary filter model settings.

If you manually specify an answer model, you can still review prompts with primary filtering if a staging model is available, even if that model has 0% usage. Inspect the usage of the answer model when sending after confirmation or sending immediately.

When you review a request containing images with Neon, the Workbench passes the full text and images directly to the staging model. If tool approval is requested during preparation or the results are empty, you can check the reason displayed and try filtering again.
